# Answering — Fix Prompt Generator — Self-Contained Worksheet Format Specification

## Problem Found
The old prompt generated by the Prompt Generator only stated:
> `Output strictly in Answering Worksheet Format v1.`

This was insufficient because an external AI receiving only the copied prompt does not have access to `docs/FORMAT.md`. Therefore, the external AI did not know the exact syntax of Answering Worksheet Format v1, leading to potential generation of incompatible worksheets.

## Implementation
The Prompt Generator was modified to include the complete Answering Worksheet Format v1 specification directly in the generated prompt. The specification covers:
- Worksheet structure (`@worksheet`, title, description)
- All four question types (mc, multi, tf, short) with examples
- Optional explanation
- Syntax rules (required fields, @end, unsupported types, etc.)
- Output restrictions (no commentary, no code fences, etc.)

The prompt is now self-contained: an external AI can generate a valid worksheet using only the generated prompt, without needing to consult `docs/FORMAT.md` or any other external documentation.

## Format Coverage
The generated prompt includes:
- Worksheet metadata: `@worksheet`, required `title`, optional `description`
- Multiple Choice (mc): exactly one correct option, options with '-', answer as 1-based index
- Multiple Select (multi): one or more correct options, answer as comma-separated 1-based indices
- True/False (tf): answer as `true` or `false` (lowercase)
- Short Answer (short): one or more accepted answers, each on a new line with '-'
- Explanation: optional, added with `explanation: ...`
- Syntax rules: `@worksheet` once, title required, every question needs type/question/answer, every question block ends with `@end`, unsupported types forbidden, required fields not omitted, option references one-based and valid
- Output restrictions: output only the worksheet, begin with `@worksheet`, end after the final `@end`, no commentary before/after, no Markdown code fences, no JSON/Markdown headings

## Real AI Test
A test was performed using the Prompt Generator to create a prompt for 5 mixed question types (Simple difficulty). The prompt was sent to an external AI (GPT-4) in a fresh conversation. The AI generated a worksheet in Answering Worksheet Format v1. The raw output was pasted into Answering's Worksheet Input screen. The parser accepted the worksheet without errors. The worksheet was then used in both Quiz and Exam modes, and the Result and Review screens displayed correctly.
