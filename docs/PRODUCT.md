# Answering — Product Definition

## 1. Product Summary

Answering is a small static web application that turns a structured worksheet into an interactive question-answering experience.

The application is a **worksheet renderer and checker**, not an LMS, question bank, AI tutor, or content-generation platform.

Questions may be created manually or generated by an external AI such as ChatGPT. The resulting worksheet is pasted into Answering, which parses and renders it.

## 2. Goals

Answering should make it easier to practice questions than reading a digital PDF and switching back and forth to an answer key.

Primary goals:

- Let users paste one complete worksheet.
- Render mixed question types interactively.
- Let users answer without seeing the answer key prematurely.
- Provide immediate feedback in Quiz Mode.
- Provide exam-like evaluation in Exam Mode.
- Provide a prompt generator for asking external AI to create compatible worksheets.
- Remain fully static and local to the browser during MVP.

## 3. Non-Goals

MVP does not include:

- authentication
- database
- cloud worksheet storage
- backend
- AI API calls
- AI answer evaluation
- collaborative worksheets
- question banks
- teacher/admin features
- analytics beyond the current worksheet session
- gamification
- accounts or profiles

## 4. Supported Question Types

### Multiple Choice

Exactly one option is correct.

### Multiple Select

More than one option may be correct. The user's selected set must match the correct set; ordering does not matter.

### True / False

The user selects True or False.

### Short Answer

The user types an answer. MVP checking is deterministic and supports multiple accepted answers.

Comparison should normalize at least:

- leading/trailing whitespace
- letter case

Advanced semantic matching is out of scope.

## 5. Future Question Type

### Essay

Essay questions are intentionally excluded from MVP because correctness requires semantic interpretation.

Future implementation may use an AI API to compare the user's response against an answer and/or rubric.

## 6. Worksheet

A worksheet is one complete input document containing:

- title
- optional description/instructions
- an ordered list of questions
- question-specific answer data
- optional explanations

A worksheet may freely mix supported question types.

Example:

```text
Question 1 → Multiple Choice
Question 2 → Short Answer
Question 3 → Multiple Select
Question 4 → True / False
```

## 7. Modes

### Quiz Mode

Purpose: learning and practice.

Behavior:

1. Show one question card.
2. User answers.
3. User submits.
4. Check the answer.
5. Immediately show correct/incorrect feedback.
6. Show the correct answer and optional explanation.
7. Allow the user to continue to the next question.

### Exam Mode

Purpose: exam simulation.

Behavior:

1. Show one question card.
2. User answers.
3. User can navigate between questions.
4. Do not reveal correctness or answer key during the exam.
5. User submits the exam.
6. Calculate the final result.
7. Allow review after submission.

The exact visual treatment of these modes belongs to `DESIGN.md` and is intentionally not specified here.

## 8. Prompt Generator

Answering provides a local prompt generator for external AI.

The user configures:

- number of questions
- question types
- difficulty
- source

### Difficulty

- Simple
- Normal
- HOTS
- Mixed

### Source

- User-provided material
- General internet knowledge

For user-provided material, the generated prompt should instruct the AI to base questions on the provided material.

For general internet knowledge, the generated prompt should allow the AI to use generally available knowledge.

The generated prompt must instruct the AI to output the Answering worksheet format.

The web does not send the prompt to an AI service. The user copies it and sends it to an AI chat manually.

## 9. Local State

MVP worksheet data and answer state exist only in the browser session.

Persistent storage is not required.

## 10. Product Boundary

The core product loop is:

```text
Get / create questions
        ↓
Convert to Answering format
        ↓
Paste worksheet
        ↓
Choose Quiz or Exam
        ↓
Answer
        ↓
Check / Submit
        ↓
Review result
```

Anything outside this loop requires explicit scope approval.
